# Security policy

## Supported versions

Security fixes go into the latest release.

## Reporting a vulnerability

Please do not open a public issue for a security problem.
Use GitHub's private reporting instead: open the **Security** tab of this repository and choose **Report a vulnerability**.

Include what you found, how to reproduce it and which version you used. You will get a reply as soon as the maintainer can.

## Good to know

Albumsmith is built for a single owner who runs it on their own server. It stores a Flickr access token in its data folder, so keep that folder private and backed up. If you expose Albumsmith to the internet, use HTTPS and put your usual access control in front of it.
