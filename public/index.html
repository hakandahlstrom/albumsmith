Albums

How this page works

This shows all your albums on Flickr, including albums that are not managed by a rule. Click an album to open it on Flickr in a new tab.

Albums with a gold frame and the label Managed by Albumsmith are kept up to date by a rule. All your other albums are left exactly as they are. Use the second box above to show only one kind.

Search and the sort box above only change how albums are shown on this page. To change the order of your albums on Flickr, use Sort albums.

Create your first managed album

Below are all the albums you already have on Flickr. Albumsmith does not change any of them. It only fills and updates albums that it creates for a rule, and those are marked with a gold frame and the label Managed by Albumsmith.

  1. Click New rule and give the album a name.
  2. Describe which photos belong in it, for example a tag, a camera or a date range.
  3. Use Count matching photos to check the result, then save the rule.
  4. Run it from the Rules page with Sync now. Use Check all if you want to review the changes first.
