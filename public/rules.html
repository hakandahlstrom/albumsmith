How this page works

Each rule describes one album on Flickr: which photos belong in it (by tags, dates or "on this day") and in what order. Click a title to edit the rule.

With Auto ticked, Albumsmith updates the album once a night. Sync now updates one album straight away. It is only available for rules with Auto ticked.

Last run shows how many photos the rule found and whether the album was changed.

As a safety net, a nightly run will not remove more than 10% of an album's photos in one go (or more than 5 photos from a small album). A rule that would is skipped and listed under Status, since Flickr's search is sometimes incomplete. Sync now skips that check, because you are looking at the result yourself.

Use Check all to compare every rule with Flickr before you turn auto-sync on.

Export rules


Rules are matched by album, so import only makes sense for the same Flickr account. A backup of the current rules is saved first.
