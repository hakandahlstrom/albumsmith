How this page works

Albumsmith updates all albums with auto-sync once a night. This page shows how the latest run went and keeps a history of recent runs.

Needs attention lists rules that failed or were skipped. A rule is skipped when it would remove many photos from an album, because Flickr's search is sometimes incomplete. If the change is intended, open Rules and use Sync now on that rule. Otherwise it is usually fine at the next run.
